# Geographic scene

The current dashboard uses a real-time 3D geographic renderer. It does not use a background photograph or generated terrain bitmap.

OpenStreetMap-derived geometry: © OpenStreetMap contributors, under the [Open Database Licence](https://www.openstreetmap.org/copyright). City building-height attributes: [Building footprints 2009](https://opendata.vancouver.ca/explore/dataset/building-footprints-2009/), under the Open Government Licence - Vancouver.

See public/data/vancouver/source-manifest.json for source details and limits. Terrain/canopy heights and missing building heights are stylized estimates. Vessel motion is simulated. Documentation previews are captures of the running renderer.
