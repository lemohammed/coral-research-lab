# Artwork

`research-strait.jpg` was generated for this project using OpenAI's built-in image generation tool on October 12, 2026, then compressed to JPEG for delivery. It recreates the monochrome point-cloud strait art direction of a visual reference supplied by the project owner. The original reference screenshot is not distributed in the public source release.

Production prompt: a wide silver channel between dense white lidar-like terrain, two white cargo vessels, an oblique aerial viewpoint, soft overcast lighting, shallow focus at the edges, and crisp central detail. No interface, lettering, logos, or orange marks were generated into the artwork. Interface elements are implemented separately.

The artwork is a decorative background, not a geographic dataset, live scan, or agent-position feed.
